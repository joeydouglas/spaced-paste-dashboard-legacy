# Spaced Paste (Dulce de Uva x Nana Glue) — Legacy Dashboard

Static, generated dashboard for the **Spaced Paste (Dulce de Uva x Nana Glue)** breeding cross.

This repository holds the **legacy generated dashboard only** (`index.html`, `style.css`,
`plants/<ID>.html`). It was split out of `joeydouglas/spaced-paste-breeding`, which is now the
**markdown data repo** (`project.md` + `plants/<ID>.md`) read by the breeding data API.

- Data repo (record of truth): https://github.com/joeydouglas/spaced-paste-breeding
- Plant ID convention: `sp01`, `sp02`, ... (parsed from Discord text via a tightly-anchored
  `\bsp[\s-]?(\d{1,2})\b` pattern — deliberately strict, since "sp" is a common English
  substring and the #breeding channel is shared with other crosses)

## Status

Legacy / transitional. The HTML here is regenerated by `generate_dashboard.py` in the project
working directory. The new frontend renders the markdown data repo instead; this repo is
retained so the existing deploy path keeps working until it is retired.

## Provenance note

Seed data for `sp06` was extracted from the Google Doc "Spaced Paste (DDU x NG)". Two
ambiguities were confirmed by Joey (2026-08-25):

- **DDU = Dulce de Uva** (confirmed).
- **NG parent = the same Nana Glue** used in the Mule Fuel x Nana Glue cross (confirmed).
